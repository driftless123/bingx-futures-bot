# Запуск бота на Oracle Cloud (бесплатно) — пошагово

Цель: бот работает 24/7 на бесплатном сервере Oracle, независимо от твоего компьютера.
Время на всё: ~30–60 минут (первый раз).

---

## Что понадобится
- Почта, телефон и **банковская карта** (Oracle проверяет личность при регистрации;
  за бесплатные ресурсы **не списывает** — карта только для верификации).
- Твой проект бота с готовым `.env` (ключи BingX + Telegram).

---

## Шаг 1. Регистрация в Oracle Cloud
1. Зайди на **cloud.oracle.com** → "Sign up" / "Start for free".
2. Заполни данные, подтверди почту и телефон, привяжи карту.
3. Выбери "Home Region" поближе (например, **Frankfurt** или **Amsterdam**) — поменять
   потом нельзя.
4. Дождись активации аккаунта (обычно сразу, иногда до нескольких минут).

---

## Шаг 2. Создание сервера (виртуальной машины)
1. В консоли: меню (≡) → **Compute → Instances → Create Instance**.
2. **Name:** любое, например `trading-bot`.
3. **Image and shape** → "Edit":
   - **Image:** выбери **Canonical Ubuntu** (22.04 или 24.04) — проще для новичка.
   - **Shape:** нажми "Change shape" и выбери **Always Free-eligible**:
     - `VM.Standard.E2.1.Micro` (AMD, 1 ГБ RAM) — самый простой, всегда доступен.
     - (Если хочешь больше памяти — `VM.Standard.A1.Flex` ARM, но он часто
       "out of capacity". Если выдаёт ошибку ёмкости — бери E2.1.Micro.)
   - Для бота 1 ГБ RAM достаточно с запасом.
4. **Add SSH keys:**
   - Выбери "Generate a key pair for me" → **скачай Private Key** (файл `.key`).
     ОБЯЗАТЕЛЬНО сохрани его — без него не подключишься. (Можно и свой ключ загрузить.)
5. Убедись, что включён **public IP** (Assign a public IPv4 address — по умолчанию да).
6. Нажми **Create**. Через минуту инстанс будет "Running".
7. Запиши **Public IP address** инстанса (на странице инстанса).

> Сеть: боту нужен только исходящий доступ (к BingX и Telegram). Входящий — только SSH
> (порт 22), он в дефолтной сети уже открыт. Ничего настраивать не нужно.

---

## Шаг 3. Подключение к серверу по SSH (с Windows)
В Windows 10/11 уже есть `ssh`. Открой **PowerShell** в папке, где лежит скачанный ключ.

```powershell
# Один раз — ограничить доступ к файлу ключа (иначе SSH ругается):
icacls .\твой_ключ.key /inheritance:r
icacls .\твой_ключ.key /grant:r "$($env:USERNAME):(R)"

# Подключение (замени ключ и IP):
ssh -i .\твой_ключ.key ubuntu@ТВОЙ_PUBLIC_IP
```

Пользователь для Ubuntu — **ubuntu**. На первый вопрос "Are you sure..." ответь `yes`.
Если подключился — ты внутри сервера.

---

## Шаг 4. Загрузка файлов бота на сервер
Самый простой способ — скопировать папку проекта с компьютера. Открой **новое** окно
PowerShell в папке, где лежит `bingx_trading_bot` (рядом с ключом), и выполни:

```powershell
scp -i .\твой_ключ.key -r .\bingx_trading_bot ubuntu@ТВОЙ_PUBLIC_IP:/home/ubuntu/
```

Это зальёт весь проект (вместе с твоим `.env`, если он там есть — по SSH это безопасно,
канал зашифрован).

> Если `.env` на сервер не попал — создашь его вручную на шаге 6.

---

## Шаг 5. Установка Python и зависимостей
Вернись в окно, где ты подключён к серверу (Шаг 3), и выполни:

```bash
cd ~/bingx_trading_bot
bash deploy/setup.sh
```

Скрипт сам обновит систему, поставит Python, создаст окружение, установит зависимости
и выставит часовой пояс (Польша). Подожди пару минут.

---

## Шаг 6. Файл .env с ключами (если не залил на шаге 4)
```bash
cd ~/bingx_trading_bot
nano .env
```
Впиши свои ключи (как в `.env.example`), сохрани: `Ctrl+O`, `Enter`, выход `Ctrl+X`.

---

## Шаг 7. Проверка запуска вручную
```bash
cd ~/bingx_trading_bot
./venv/bin/python main.py
```
Если в Telegram пришло "бот запущен" и в консоли пошли логи — всё работает.
Останови пока что: `Ctrl+C` (сейчас настроим автозапуск, чтобы работал сам).

---

## Шаг 8. Автозапуск (чтобы бот сам стартовал и не падал)
Это главное ради чего всё затевалось — бот будет работать 24/7, перезапускаться
при сбое и стартовать после перезагрузки сервера.

```bash
# Скопировать сервис в систему:
sudo cp ~/bingx_trading_bot/deploy/bot.service /etc/systemd/system/bot.service

# Включить и запустить:
sudo systemctl daemon-reload
sudo systemctl enable bot
sudo systemctl start bot

# Проверить статус:
sudo systemctl status bot
```
Если статус "active (running)" — готово, бот живёт на сервере.

Теперь можешь закрыть PowerShell и выключить свой компьютер — бот продолжит торговать.

---

## Полезные команды (на будущее)
```bash
sudo systemctl status bot      # статус
sudo systemctl restart bot     # перезапустить (после смены настроек)
sudo systemctl stop bot        # остановить
journalctl -u bot -f           # смотреть логи бота вживую
tail -f ~/bingx_trading_bot/logs/bot.log   # лог-файл бота
```

### Как обновить настройки/код потом
1. Поменяй файл локально, залей заново через `scp` (Шаг 4), **или** правь прямо на
   сервере через `nano`.
2. `sudo systemctl restart bot`

---

## Частые проблемы
- **SSH "Permission denied":** не тот ключ или не выполнил `icacls` (Шаг 3).
- **Shape "out of capacity":** ARM-инстансы заняты — выбери `VM.Standard.E2.1.Micro`.
- **Бот не шлёт в Telegram:** проверь `.env` на сервере (`nano .env`) — ключи на месте?
- **Время отчёта не то:** проверь пояс — `timedatectl`. Должно быть Europe/Warsaw.
  Сменить: `sudo timedatectl set-timezone Europe/Warsaw`, затем `sudo systemctl restart bot`.

---

## Важное про безопасность
- В `.env` — твои API-ключи. Не давай к серверу доступ посторонним.
- На ключах BingX НИКОГДА не включай право "Вывод средств" (Withdraw).
- Храни приватный SSH-ключ в надёжном месте.
