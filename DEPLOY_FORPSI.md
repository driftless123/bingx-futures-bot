# Запуск бота на VPS Forpsi.pl — пошагово

Цель: бот работает 24/7 на платном сервере Forpsi, независимо от твоего компьютера.
Время на всё: ~30 минут (первый раз).

> Эта инструкция для входа под **root** (так Forpsi даёт VPS по умолчанию).

---

## Шаг 1. Заказ VPS
1. Зайди на **forpsi.pl** → **Serwery VPS** (https://www.forpsi.pl/serwery-vps/).
2. Выбери **самый дешёвый Linux-тариф** — для бота хватит 1 vCPU, 1–2 ГБ RAM, SSD.
   (Точную цену смотри на сайте — у польских провайдеров входной VPS обычно ~15–40 zł/мес.
   Бери минимальный, бот крошечный.)
3. При заказе как систему выбери **Ubuntu** (22.04 или 24.04) — проще для новичка.
4. Оплати. Сервер будет готов за несколько минут.

---

## Шаг 2. Получи доступ
После активации Forpsi пришлёт (на почту / в панели клиента):
- **IP-адрес** сервера
- **root-пароль** (или данные для входа)

Запиши их.

---

## Шаг 3. Подключение по SSH (с Windows)
В Windows 10/11 уже есть `ssh`. Открой **PowerShell** и выполни (подставь свой IP):

```powershell
ssh root@ТВОЙ_IP
```
Введи root-пароль (при вводе символы не отображаются — это нормально).
На вопрос "Are you sure..." ответь `yes`. Если вошёл — ты внутри сервера.

---

## Шаг 4. (Рекомендую) базовая безопасность
Смени root-пароль на свой надёжный:
```bash
passwd
```
Этого для старта достаточно. (Позже можно настроить вход по SSH-ключу — спроси, подскажу.)

---

## Шаг 5. Загрузка файлов бота на сервер
Открой **новое** окно PowerShell в папке, где лежит `bingx_trading_bot`, и выполни:

```powershell
scp -r .\bingx_trading_bot root@ТВОЙ_IP:/root/
```
Введи пароль. Это зальёт весь проект (вместе с `.env`, если он там есть — по SSH безопасно).

> Если `.env` не попал — создашь вручную на шаге 7.

---

## Шаг 6. Установка Python и зависимостей
Вернись в окно, где подключён к серверу, и выполни:
```bash
cd ~/bingx_trading_bot
bash deploy/setup.sh
```
Скрипт сам обновит систему, поставит Python, создаст окружение, установит зависимости
и выставит часовой пояс (Польша). Подожди пару минут.

---

## Шаг 7. Файл .env с ключами (если не залил на шаге 5)
```bash
cd ~/bingx_trading_bot
nano .env
```
Впиши ключи (как в `.env.example`), сохрани: `Ctrl+O`, `Enter`, выход `Ctrl+X`.

---

## Шаг 8. Проверка запуска вручную
```bash
cd ~/bingx_trading_bot
./venv/bin/python main.py
```
Пришло в Telegram "бот запущен" и пошли логи — всё ок. Останови: `Ctrl+C`.

---

## Шаг 9. Автозапуск (бот работает сам 24/7)
```bash
# Скопировать службу (версия для root):
sudo cp ~/bingx_trading_bot/deploy/bot-root.service /etc/systemd/system/bot.service

sudo systemctl daemon-reload
sudo systemctl enable bot
sudo systemctl start bot
sudo systemctl status bot
```
Статус "active (running)" — готово! Бот живёт на сервере. Можешь закрыть PowerShell
и выключить свой компьютер — бот продолжит торговать, сам перезапустится при сбое
и после перезагрузки сервера.

---

## Полезные команды
```bash
sudo systemctl status bot      # статус
sudo systemctl restart bot     # перезапустить (после смены настроек)
sudo systemctl stop bot        # остановить
journalctl -u bot -f           # логи бота вживую
tail -f ~/bingx_trading_bot/logs/bot.log   # лог-файл
```

### Как обновить настройки/код потом
1. Поменяй файл локально → залей заново через `scp` (Шаг 5), **или** правь на сервере
   через `nano`.
2. `sudo systemctl restart bot`

---

## Частые проблемы
- **SSH "Connection refused/timeout":** проверь IP; у Forpsi SSH (порт 22) обычно открыт.
- **"command not found: scp/ssh":** у тебя старая Windows — поставь OpenSSH или используй
  программу WinSCP / PuTTY.
- **Бот не шлёт в Telegram:** проверь `.env` на сервере (`nano .env`).
- **Время отчёта не то:** `timedatectl` → должно быть Europe/Warsaw. Сменить:
  `sudo timedatectl set-timezone Europe/Warsaw`, затем `sudo systemctl restart bot`.

---

## Безопасность
- В `.env` твои API-ключи — не давай доступ к серверу посторонним.
- На ключах BingX НИКОГДА не включай "Вывод средств" (Withdraw).
- Смени root-пароль (Шаг 4) на надёжный.
